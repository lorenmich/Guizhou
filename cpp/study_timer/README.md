# 学习时间记录器（C++ 命令行版）

2026-10-10 学习用项目。记录各科累计学习分钟数，命令行操作，数据只存在内存里。

## 这次做了什么

- 目标：练输入处理、循环、函数拆分、多文件组织
- 完成：菜单循环、添加记录、查看统计、退出
- 没完成：非整数输入的健壮处理、数据持久化

## 当时的知识状态

- 会：变量、条件、循环、函数、数组
- 还没学：流状态、输入缓冲区、异常
- 这是后来回看时判断"当时为什么这么写"的依据

## 功能

- 添加学习记录：选科目（C / Python / Math / English 四科写死），输入分钟数
- 查看统计：显示单科累计、总分钟数、有效记录条数
- 输入限制：分钟数 1—240，超出提示重试
- 菜单可反复操作，选 0 退出

## 文件结构

- `main.cpp`：程序入口，主循环和菜单分发
- `do.h`：函数声明
- `do.cpp`：函数定义

## 编译运行

```bash
g++ main.cpp do.cpp -o main
./main
```

## 已知问题

非整数输入会死循环。三处 std::cin >> 都没有检查流状态，输入字母后流进入失败态，坏字符留在缓冲区，循环卡死。

数据只在内存里，退出后全部丢失。

只有 4 科，写死在代码里。

## 这次学到的东西

函数声明放头文件，定义放 .cpp，main.cpp 包含头文件后调用

多文件编译时把 .cpp 一起交给编译器

自己发现 std::cin 读失败后不会自动恢复，需要处理流状态和缓冲区
